AMAZING ASSISTANT ONLINE
A job marketplace where clients post jobs and freelancers apply.


HOW TO OPEN IT
--------------
1. Unzip first: right-click the zip > Extract All.
2. Open the extracted folder.

Windows: double-click run.bat. Nothing to install; Python is included in the
         "python" folder. If Windows shows "Windows protected your PC", click
         More info > Run anyway.
Mac:     needs Python 3.10 or newer (free): https://www.python.org/downloads/
         Then double-click run.command (if macOS blocks it: right-click > Open).
         The first Mac start takes about a minute and needs internet.

Your browser opens http://127.0.0.1:5050 by itself. Keep the black window open while you
use the site. Close it (or press Ctrl+C) to stop.

Do not open the .html files in the templates folder directly. They only work
through the running site.

IF YOU SEE "This site can't be reached" / "127.0.0.1 refused to connect":
the site is not running. Unzip the folder first (right-click > Extract All),
double-click run.bat (or run.command), and keep its black window open. Closing
that window stops the site. If the window shows an error, send a screenshot.

THINGS TO TRY
-------------
1. Three designs: use the "Design: Classic | Loop | Care" switch in the bottom-right
   corner of any page.
2. As a client (maya@hanap.test): Post a job, then Dashboard > Review to read
   applications and mark people Shortlisted, Hired, or Declined.
3. As a freelancer (andre@hanap.test): Jobs > open a job > apply with a short
   letter and a rate. Your Dashboard shows where each application stands.
4. Reviews: after a client marks someone Hired, both sides can leave a
   1-5 star review. Reviews show on each person's profile.
5. Browse by category from the homepage grid, or filter on the Jobs page.


GOOD TO KNOW
------------
- Everything is stored on this computer in the "data" folder. Delete that
  folder to reset the site to the sample data.
- Fonts, animations, and smooth scrolling load from the internet. Without a
  connection the site still works, just with plainer fonts and no animation.
